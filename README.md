# Геометрия интеллекта

Серия эссе о том, как математика описывает различия между людьми и восприятие человека человеком.

**Ведущий язык — русский.** Английские версии производны: правка вносится сначала в `ru.md`, английский догоняет, когда русский устоялся. Публикация — на английском, на Substack.

## Вспомогательное

- `material/series-spec.md` — сводная спека по всему незаписанному остатку серии: очередь, несущие тезисы, сквозные правила, открытые решения.
- `material/topology.md` — топологическая ветка, отложена на неопределённый срок (01.08.2026); не в текущей очереди, но не забыта.
- `material/group-dynamics.md` — группы больше двух, пол как переменная; дальний горизонт, вне очереди.
- `material/sources.md` — единый список источников серии; приёмка обязательна перед каждой публикацией.
- `material/roles.md` — участники и маршрут черновика.
- `observatory/` — код-проект по мотивам №1 (своя спецификация внутри).

## Как ведётся работа

1. Правка — сначала в русский файл эссе, отдельным коммитом с внятным сообщением.
2. Английская версия обновляется следом, когда русская устоялась.
3. Находки из обсуждений вносятся в черновик только после решения автора.
4. Ветка одна — `main`. Ветки под отдельное эссе заводятся только при долгой возне над черновиком.

## Файлы для публикации

Для каждого эссе два HTML: `essayN-final-github-html.html` — полный документ с обвязкой, для просмотра в репозитории; `essayN-substack.html` — только содержимое `<body>`, без заголовка и эпиграфа, для вставки в редактор Substack (заголовок и подзаголовок вносятся в отдельные поля). Формулы в обоих полужирным, а не `<code>`: моноширинные вставки Substack ломает.
